# Snypse Gallery

Portable commercial showcase for Snypse / Magfi creative previews.

## Preview
The site is a static, responsive gallery prepared for GitHub Pages.

## Asset structure
Upload approved creative files to `assets/` using these names:

- `br-autos-13.png`
- `br-autos-07.mp4`
- `br-finance-10.png`
- `br-entertainment-06.png`
- `beauty-01.png`
- `travel-01.png`

The gallery already references these paths.
